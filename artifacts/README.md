# artifacts/

Purpose: evidence that something works or happened. Not source code, not plans.

| Path | Holds |
|---|---|
| `screenshots/` | Screenshots of the running app or wireframes. |
| `test-output/` | Saved test and UAT run output. |

File name: `YYYY-MM-DD-what-it-shows.ext`.

Each artifact should be referenced from the plan or decision it supports.

`2026-10-14-demo-balance.png` is in `screenshots/`. PNGs in `../static/wireframes/` stay where they are for now.
